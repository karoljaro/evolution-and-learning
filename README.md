# Evolution and Learning

Exploring genetic algorithms and neural networks through practical implementations and experiments in Python.

This repository includes coursework for the **Genetic Algorithms and Artificial Neural Networks** university course, alongside personal experiments and extensions.

## Topics

- Genetic algorithms and evolutionary optimization
- Binary representations, selection, crossover, and mutation
- Constraint handling and the knapsack problem
- Neural networks

## Repository structure

Experiments are organized into topic-based directories. Jupyter notebooks include explanations, code, visualizations, and conclusions.

## Tools

Python · Jupyter · NumPy · Matplotlib
